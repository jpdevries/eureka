Eureka 🌲 the progressively enhanced media browser

Eureka connects to your media sources through a small REST API and lets people browse directories, upload, rename, delete, crop and choose files. Version 3 is a written specification with a framework-free reference implementation: a custom element, a stylesheet, a Node server, and a React wrapper over the element.

Try it

  • Server-rendered

    The server returns a working HTML form. The element takes over when the script arrives. Turn JavaScript off and it still browses, uploads and chooses.

  • Client-only

    An empty <eureka-browser api="…"> that fetches sources, tree and listing itself.

  • React

    <EurekaBrowser> from @mrktps/eureka-react with a side panel reading the browser's state through a hook.

  • Embed

    The modal pattern: a text editor opens the browser in a dialog and inserts what was chosen.

The sample library is generated on first start, so uploading, renaming and deleting are safe to try. The uploads source starts empty.

Three levels

LevelWhat runsWhat works
0HTML onlyBrowse by directory selector, upload, choose; every view mode as a synchronous form.
1Element with scriptInstant navigation, sort, filter, keyboard shortcuts, dialogs for rename, delete, new directory and crop, drag-and-drop and paste upload, persistence.
2Capable browsersNative dialogs, container queries, CSS masonry where supported, a worker for sorting, filtering and formatting, fullscreen.

Use it

Everything is published as @mrktps/eureka* packages. The element works with any server that speaks the REST API; the reference server does over a directory on disk.

<link rel="stylesheet" href="/assets/css/eureka.css">
<div class="eureka-root">
  <eureka-browser api="/media-api/" assets="/assets/"></eureka-browser>
</div>
<script type="module" src="/assets/js/eureka-browser.js"></script>
import { EurekaBrowser, useEurekaState } from '@mrktps/eureka-react';

<EurekaBrowser api="/media-api/" assets="/assets/" onChoose={(items) => insert(items)} />
npx eureka-server --root ./media --render --enhance

Keyboard users: press Alt+Shift+S (or /) to filter, arrow keys to move between items, Enter to choose, F2 to rename. The full map is in the keyboard spec.
