# @mrktps/eureka-css

## 3.0.0-alpha.1

### Patch Changes

- First published alpha of Eureka 3: the framework-free core, the HTML
  renderers, the stylesheet, the `<eureka-browser>` element, the React
  wrapper and the reference Node server, as specified in `spec/` and
  verified by the conformance suite (Level 0, enhanced and narrow projects,
  axe clean). Highlights since the 2.0 line: one spec and one conformance
  suite for every implementation, native dialogs and masonry without
  JavaScript layout, a worker for parsing, sorting and filtering (5,000
  items in about a second), keyboard navigation as a WAI-ARIA grid with a
  built-in shortcuts reference, message catalogs as files, and a React 19
  adapter. See `docs/migrating-from-v2.md`.
